# 🎣 안티그래비티 (Anti-Scam Reply Generator)

로맨스 스캠 및 암호화폐 투자 사기꾼의 메시지를 붙여넣으면, **사기꾼의 시간과 멘탈을 털어버리는 3가지 방어 답변**을 생성해주는 Next.js 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **상대방 메시지 즉시 분석**: 사기꾼의 수법(투자 유도, 개인정보 캐기, 악성 앱 링크 등)을 실시간 분석
2. **3가지 맞춤형 방어 전략 생성**:
   - 🌲 **#삼천포전환**: 진지한 멘트 속 엉뚱한 단어(날씨, 음식, 칠리크랩 등)에 꽂혀 대화 주제 이탈
   - ⏳ **#무한지연 / #핑계왕**: 극도의 호감을 표하지만 황당한 핑계(화면 기포, 고양이 방해 등)로 실행 회피
   - ❓ **#피곤한역질문**: 상대를 극찬하더니 답하기 귀찮은 엉뚱한 질문을 던져 주도권 탈환
3. **철저한 개인정보 보호**: 사용자의 나이, 직업, 거주지, 자산 등 실제 정보는 1도 노출되지 않도록 설계
4. **원클릭 복사 & 모바일 친화적 UI**: 다크모드 기반의 깔끔한 카드 레이아웃과 클립보드 원클릭 복사
5. **무료 Gemini API 연동**: 서버 환경변수 설정 또는 웹 UI에서 본인의 API Key를 직접 입력하여 즉시 사용 가능

---

## 🚀 로컬 실행 방법

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **환경변수 설정 (선택사항)**
   `.env.example` 파일을 복사하여 `.env.local`을 생성하고 Google AI Studio 키를 입력합니다.
   (입력하지 않아도 웹 UI 상단 **[Gemini API 키]** 버튼을 통해 브라우저에서 직접 입력 가능합니다)
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

---

## 🌐 Vercel 무료 배포 방법

1. 본 프로젝트를 GitHub 저장소에 Push합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **[Add New Project]** 를 누르고 해당 GitHub 리포지토리를 불러옵니다.
3. **Environment Variables** 설정에서 아래 환경변수를 추가합니다:
   - `GEMINI_API_KEY`: Google AI Studio에서 발급받은 무료 API 키
4. **[Deploy]** 버튼을 누르면 약 1분 내로 배포가 완료됩니다!

## 🛡️ 5대 방어 골든 룰

| 번호 | 전략명 | 내용 |
|---|---|---|
| 1 | **정보 차단** | 개인정보 질문에는 "그냥 회사원이에요", "동네 살아요"처럼 극도로 모호하게 대답 |
| 2 | **가짜 호감 + 백치미** | 상대방의 수익 자랑을 치켜세우되 본인은 완벽한 기계치/금융치로 포지셔닝 |
| 3 | **무한 지연과 핑계** | 링크 클릭/앱 설치 요청 시 기상천외한 사유로 무한정 미룸 |
| 4 | **삼천포 화제 전환** | 진지한 코인/수익 대화를 음식, 모기, 롱패딩 이야기로 전환 |
| 5 | **피곤한 역질문** | 답변 끝에 상대방을 피곤하게 만들 맥 빠지는 질문을 덧붙임 |
