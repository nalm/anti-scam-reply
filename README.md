# 🎣 안티그래비티 (Anti-Scam Reply Generator)

로맨스 스캠 및 암호화폐 투자 사기꾼의 메시지를 붙여넣으면, **사기꾼의 시간과 멘탈을 털어버리는 3가지 방어 답변**을 Claude 3.5 AI가 생성해주는 Next.js 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **상대방 메시지 즉시 분석**: 사기꾼의 수법(투자 유도, 개인정보 캐기, 악성 앱 링크 등)을 실시간 분석
2. **3가지 맞춤형 방어 전략 생성**:
   - 🌲 **#삼천포전환**: 진지한 멘트 속 엉뚱한 단어(날씨, 음식, 칠리크랩 등)에 꽂혀 대화 주제 이탈
   - ⏳ **#무한지연 / #핑계왕**: 극도의 호감을 표하지만 황당한 핑계(화면 기포, 고양이 방해 등)로 실행 회피
   - ❓ **#피곤한역질문**: 상대를 극찬하더니 답하기 귀찮은 엉뚱한 질문을 던져 주도권 탈환
3. **철저한 개인정보 보호**: 사용자의 나이, 직업, 거주지, 자산 등 실제 정보는 1도 노출되지 않도록 설계
4. **원클릭 복사 & 모바일 친화적 UI**: 다크모드 기반의 깔끔한 카드 레이아웃과 클립보드 원클릭 복사
5. **Anthropic Claude 3.5 연동**: 서버 환경변수(`ANTHROPIC_API_KEY`) 설정 또는 웹 UI에서 본인의 Claude API Key를 직접 입력하여 즉시 사용 가능

---

## 🚀 로컬 실행 방법

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **환경변수 설정 (선택사항)**
   `.env.example` 파일을 복사하여 `.env.local`을 생성하고 Anthropic API 키를 입력합니다.
   (입력하지 않아도 웹 UI 상단 **[Claude API 키]** 버튼을 통해 브라우저에서 직접 입력 가능합니다)
   ```env
   ANTHROPIC_API_KEY=sk-ant-api03-...
   ```

3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

---

## 🌐 Vercel 무료 배포 방법

1. GitHub 리포지토리 연동 후 Vercel에서 배포합니다.
2. **Environment Variables** 설정:
   - `ANTHROPIC_API_KEY`: Anthropic Console에서 발급받은 API 키
3. 배포 완료 후 즉시 사용 가능합니다.
